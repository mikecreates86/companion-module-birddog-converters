# 2.1.3
**What's fixed**
- In the connection settings, the Save button stayed grey until the "restart video every N hours" box was edited. That box is now a simple list (Never, every hour, every 2 hours, and so on) set to "Never" by default, so Save works straight away. If you typed in a number of hours before, it keeps working, but pick your schedule from the list so it shows correctly.

**How to install:** download `birddog-converters-2.1.3.tgz` below, then in Companion use Modules > Import module package.
