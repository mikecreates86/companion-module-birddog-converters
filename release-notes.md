# 2.1.2
**What's fixed**
- In the connection settings, the Save button stayed grey after turning on "Auto-recover when the NDI feed drops and returns". The "Also restart video after the feed returns" option is now always shown instead of appearing only after auto-recover is turned on, which should let Save turn green right away.

**How to install:** download `birddog-converters-2.1.2.tgz` below, then in Companion use Modules > Import module package.
